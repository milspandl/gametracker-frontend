# GameTracker – Frontend

Este es el frontend del proyecto **GameTracker**, una aplicación web para organizar una biblioteca personal de videojuegos, agregar reseñas y ver estadísticas simples de uso.

El frontend fue desarrollado en **React + Vite + TypeScript**, usando Axios para comunicarse con el backend.

---

## 🚀 Funcionalidades principales

- Ver la biblioteca de videojuegos
- Agregar juegos con título, género, portada, horas y puntuación
- Mostrar tarjetas con diseño moderno
- Ver estadísticas básicas (cantidad de juegos)
- Leer y escribir reseñas
- Interfaz oscura, limpia y responsiva
- Conexión directa al backend (Node + Express + MongoDB)
